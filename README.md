# Air Draw

macOS 웹캠으로 손을 추적해 화면 위에 그리는 앱입니다. 전체화면 카메라 배경이 기본이며, 하단 버튼 또는 메뉴 막대에서 투명 오버레이로 전환할 수 있습니다. 오버레이는 마우스 입력을 통과시키므로 화면에 영상이나 그림이 있어도 아래 앱을 클릭할 수 있습니다. 하단 조작 버튼, 작은 프리뷰와 결과 패널 영역은 입력을 받습니다.

## 실행

```bash
cd ~/air-draw
.venv/bin/python main.py
```

화면 아래 중앙의 **앱 종료** 버튼으로 종료할 수 있습니다. **전체화면 끄기** 버튼은 웹캠 배경을 끄고 투명 오버레이로 전환합니다. 버튼은 프리뷰를 숨겨도 항상 표시되고 마우스로 클릭할 수 있습니다. 메뉴 막대 종료, 프리뷰에 포커스한 상태의 Ctrl+Option+Q, 실행 터미널의 Ctrl+C도 사용할 수 있습니다.

## 설치 / 환경 복원

기존 `.venv`가 있으면 그대로 사용하세요. 이 프로젝트는 Python 3.12와 MediaPipe 1.0.0으로 검증되었습니다.

```bash
cd ~/air-draw
uv venv --python 3.12 .venv
uv pip install --python .venv/bin/python -r requirements.txt
mkdir -p models
curl -L --fail https://storage.googleapis.com/mediapipe-models/hand_landmarker/hand_landmarker/float16/latest/hand_landmarker.task -o models/hand_landmarker.task
```

MediaPipe 1.0.1은 이 Mac의 arm64 환경에서 네이티브 크래시가 발생해 `mediapipe==1.0.0`을 고정했습니다. `mp.solutions` 대신 Tasks API를 사용합니다. `opencv-contrib-python`이 MediaPipe 의존성으로 설치되므로 `opencv-python`을 별도로 중복 설치하지 마세요.

Codex CLI가 설치되고 ChatGPT 계정으로 로그인되어 있어야 AI 생성이 가능합니다. API 키는 사용하지 않습니다. 기본 CLI 경로는 `~/.local/bin/codex`이며 다른 경로는 `config.py`의 `CODEX_BINARY`로 변경합니다. 비대화형 실행과 이미지 첨부 플래그는 로컬 CLI 도움말로 확인했으며, CLI 0.159.3에서 실제 이미지 생성까지 검증했습니다. 생성은 계정 사용량을 소비합니다.

## 권한

카메라 접근이 실패하면 시스템 설정 → 개인정보 보호 및 보안 → 카메라에서 실행에 사용한 터미널 또는 IDE를 허용하고 다시 실행하세요. 카메라는 권한 요청을 위해 메인 스레드에서 엽니다.

단축키는 프리뷰에 포커스했을 때만 동작하는 Qt 단축키입니다. 전역 키 감시를 하지 않으므로 손쉬운 사용 / 입력 모니터링 권한이 필요하지 않습니다. 화면을 캡처하지 않으므로 화면 기록 권한도 사용하지 않습니다.

## 손동작

| 동작 | 사용법 |
| --- | --- |
| 그리기 | 검지를 펴고 움직이기. 엄지나 다른 손가락이 조금 펴져 있어도 허용하며, 손바닥 전체 펼침은 그리지 않습니다. 현재 선택 색으로 그립니다. |
| 펜 업 | 주먹 쥐기 또는 손을 카메라 밖으로 빼기. 현재 획을 확정합니다. |
| 색 / 도구 선택 | 검지 끝을 오른쪽 위 `Color` 칸에 가져가면 중앙 팔레트가 열립니다. 원하는 색 또는 지우개 원에 0.5초 머무르면 선택됩니다. 두 손가락 자세는 필요하지 않습니다. 선택하면 자동으로 닫히며 손끝을 선택 영역 밖으로 옮기면 그리기를 재개합니다. |
| 지우개 | 팔레트 마지막 ‘지우개’를 선택한 뒤 검지만 펴서 선 위를 지나가기. 선 일부를 지웁니다. 색을 고르면 펜으로 돌아갑니다. |
| 전체 지우기 | 검지 끝을 왼쪽 아래 ‘지우기’에 0.8초 머무르기. |
| 획 이동 | 선 가까이에서 엄지·검지 핀치를 유지하며 움직이기. 손끝 사이의 중심을 커서로 사용합니다. 풀면 놓습니다. |
| 획 던져 삭제 | 핀치로 획을 잡은 뒤 화면 가장자리 밖을 향해 빠르게 던지세요. 화면 밖으로 이동하거나, 빠른 바깥 방향 움직임 직후 가장자리에서 핀치를 풀거나 손이 사라지면 잡은 획만 삭제합니다. 느리게 옮기거나 화면 안쪽에서 손이 사라지면 삭제하지 않습니다. |
| AI 생성 | 두 손을 펼친 상태에서 0.8초 안에 바깥으로 벌리기. 엄지를 제외한 네 손가락 중 세 개의 펼침을 확인하며, 0.15초 이내 인식 누락은 허용합니다. 그림이 있어야 작동합니다. 하단 ‘AI 그림 만들기’ 버튼으로도 같은 확대·페이드아웃과 생성을 실행할 수 있습니다. |
| 새 그림 | 결과가 표시된 상태에서 주먹을 2초 유지하기. |

주먹과 핀치의 혼동을 줄이기 위해 손끝 거리뿐 아니라 손가락의 펼침 거리도 확인합니다. 손목부터 중지 MCP까지의 크기로 핀치 거리를 정규화합니다. 한 손을 추적 중일 때 다른 손이 추가되어도 같은 handedness를 우선 사용합니다.

그리기 중 0.2초 이내의 일시적인 제스처 흔들림 또는 손 인식 누락에는 획을 확정하지 않아 같은 획으로 이어집니다. 불확실한 프레임에서는 새 점을 추가하지 않습니다. 주먹은 점 추가를 즉시 중단하고 디바운스 확인 후 획을 확정합니다. 손을 오래 숨기거나 Color 칸에 진입하면 획을 확정합니다. 중앙 팔레트가 열린 동안에는 선이 그려지지 않습니다.

## 메뉴 막대와 단축키

화면 아래 중앙의 버튼으로 전체화면 전환, 작은 카메라 표시/숨김, 사용법, 앱 종료를 조작합니다. 화면 위쪽 메뉴 막대의 파란 펜 아이콘(Air Draw)에서도 모든 명령을 실행할 수 있습니다. 키보드는 작은 카메라 프리뷰를 클릭한 뒤 아래 조합을 사용하세요. 다른 앱에 포커스했을 때는 동작하지 않습니다.

| Ctrl+Option + 키 | 기능 |
| --- | --- |
| C | 전체 지우기 |
| Z | 마지막 획 취소 (지우개 작업 복원은 지원하지 않음) |
| G | AI 생성 강제 실행 |
| D | 디버그 표시와 프리뷰 랜드마크 번호 토글 |
| P | 작은 프리뷰 숨김 / 표시 |
| H | 손동작 / 단축키 안내 토글 |
| V | 전체화면 카메라 배경 / 투명 모드 전환 |
| Q | 종료 |

프리뷰를 숨긴 뒤에는 메뉴 막대에서 다시 켜세요. 메뉴 막대를 사용할 수 없는 환경에서는 프리뷰 숨김을 막아 조작 경로를 유지합니다. 프리뷰를 숨겨도 손 추적과 전체화면 카메라 배경은 계속 동작합니다. 생성·연출·결과·오류 화면에서는 지우기/취소/재생성 명령을 막고, 프리뷰·도움말·카메라 모드 전환과 종료는 허용합니다.

디버그에는 상태, 후보/확정 제스처, 손가락별 펼침 비율과 ↑/↓ 판정, 핀치 비율, 양손 손목 거리/프레임 폭을 표시합니다. 핀치 `inf`는 손이 너무 작거나 주먹 방지 조건에서 제외되었다는 뜻입니다.

## 생성 결과와 파일

스케치는 흰 배경 1024×1024 PNG로 중앙 정렬하고 획 데이터를 JSON으로 함께 저장합니다. 웹캠 배경, HUD, 커서 등은 생성 이미지에 포함되지 않습니다.

- `output/sketch_<timestamp>.png`: Codex에 전달하는 원본 스케치
- `output/sketch_<timestamp>.json`: 획 ID, 점, 색, 두께, bbox
- `output/result_<timestamp>.png`: AI 결과
- `output/codex_<timestamp>.log`: CLI stdout/stderr
- `gallery/result_<timestamp>.png`: 결과 패널의 저장 버튼으로 복사한 이미지

생성 중에도 카메라 추적과 아래 앱 사용은 계속됩니다. 결과 패널에는 원본 스케치 썸네일이 표시됩니다. 닫기는 원래 획으로 돌아가며, 주먹 2초는 획을 지우고 새 그림을 시작합니다. 실패 또는 기본 180초 타임아웃이면 오류를 3초 표시한 뒤 원래 획을 복구합니다. 종료/타임아웃 시 실행 중인 Codex 프로세스 그룹을 종료합니다. 이미 저장된 파일은 유지됩니다.

## 튜닝

모든 값은 `config.py`에서 변경합니다.

- 투명 모드에서 손 움직임이 너무 커야 화면 끝에 닿으면 `MAP_REGION_W/H`를 낮추세요 (기본 0.7). 전체화면 카메라 모드는 영상 전체와 같은 좌표로 매핑하므로 이 설정을 사용하지 않습니다.
- 투명 모드에서 커서 떨림이 크면 `CURSOR_EMA_ALPHA`를 낮추세요. 반응이 느리면 높이세요. 카메라 모드에서는 영상 속 손끝과 위치를 맞추기 위해 커서 EMA 지연을 제거합니다. 핀치 커서는 엄지·검지 중간점을 표시합니다.
- 손가락 판정은 `FINGER_EXTEND_RATIO`, 전환 지연은 `GESTURE_DEBOUNCE_FRAMES`, 그리기 시작은 `DRAW_START_FRAMES`로 조절합니다.
- 그리기는 검지의 3D 거리 / PIP 각도로 판정합니다. `DRAW_INDEX_ENTER_RATIO`, `DRAW_INDEX_HOLD_RATIO`, `DRAW_INDEX_MIN_ANGLE`을 사용하고 시작은 기본 1프레임입니다. 시작보다 유지 조건을 느슨하게 해 작은 굽힘으로 끊기는 것을 줄입니다.
- 짧은 인식 누락을 같은 획으로 연결하는 시간은 `STROKE_GAP_SECONDS`입니다 (기본 0.2초).
- 핀치가 잘 안 잡히면 `PINCH_ENTER_RATIO`를 조금 올리세요. 해제 떨림은 더 큰 `PINCH_RELEASE_RATIO`로 완화합니다. 주먹 오인은 `PINCH_INDEX_REACH_RATIO`와 `PINCH_THUMB_REACH_RATIO`로 조절합니다.
- 잡기 범위는 `GRAB_HIT_DISTANCE`, 지우개 크기는 `ERASER_RADIUS`, 선 두께는 `STROKE_THICKNESS`입니다.
- 던지기 삭제는 `THROW_MIN_SPEED`, `THROW_MIN_DISTANCE`, `THROW_EDGE_MARGIN`, `THROW_WINDOW_SECONDS`, `THROW_RELEASE_SECONDS`로 조절합니다. 가장자리 방향 이동 속도와 최근 이동량을 함께 확인합니다.
- 생성이 너무 쉽게 켜지면 `SPREAD_MIN_INCREASE` 또는 `SPREAD_CONFIRM_FRAMES`를 높이세요. 펼친 손을 유지하는 동안에는 재발동하지 않으며 포즈 해제와 쿨다운 뒤에 다시 작동합니다.
- 카메라 배경 기본값은 `CAMERA_BACKGROUND_DEFAULT`, 생성 대기 시간은 `CODEX_TIMEOUT_SECONDS`, 이미지 설명은 `CODEX_PROMPT`입니다.
- 입력은 1280×720 / 30fps입니다. 전체화면 배경은 이 영상을 화면에 맞춰 늘리므로 화면 비율이 다르면 영상 비율도 달라집니다. 성능이 떨어지면 먼저 카메라 해상도를 낮추세요.

## 최종 확인

1. 카메라 전체화면과 투명 모드를 전환하고 아래 앱 클릭이 가능한지 확인합니다.
2. 하단 ‘전체화면 끄기’와 ‘앱 종료’ 버튼이 보이고 클릭되는지 확인합니다. 작은 프리뷰를 숨겨도 버튼이 유지되는지 확인합니다.
3. 전체화면 카메라에서 검지 끝과 커서가 화면 중앙 및 모서리 근처에서 일치하는지 확인합니다. 프리뷰 클릭 후 단축키도 확인합니다.
4. 팔레트에서 지우개를 고른 뒤 선 일부만 지워지고, 색을 선택하면 다시 그려지는지 확인합니다.
5. 디버그 번호 / 비율과 사용법 안내를 토글합니다.
6. 색 선택, 획 이동, AI 생성, 결과 저장 / 닫기 / 새 그림까지 확인합니다.
7. 하단 앱 종료 버튼으로 종료하고 카메라 사용 표시가 꺼지는지 확인합니다.

메인 디스플레이 전체화면만 대상으로 합니다. 모든 Space 및 전체화면 앱 위 표시에는 PyObjC NSWindow 설정을 사용합니다.
